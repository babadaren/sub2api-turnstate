批量导入

支持 host:port:user:password、host:port user:password、HTTP/HTTPS/SOCKS5 URL，以及分行的“地址”和“用户密码”。裸地址默认 HTTP；协议不确定时先检查出口，不会自动发送模型请求。

独立探测上游连接

不改 sub2api 源码或账号代理。优先使用本机读取：选择管理员批准的账号和 API Key 编号，后台同步最新 Access Token，无需手动复制。Refresh Token 仍由 sub2api 管理，本扩展不读取或刷新它。节点探测不计入 sub2api 账本，仍可能计费。

从本机 sub2api 读取（推荐）

每约 60 秒同步一次。仅保存所选编号，不把同步 Token 复制到节点配置；账号停用、密钥撤销、Token 到期或同步过旧时暂停独立认证并退回 sub2api。数据库审批范围由服务器 root 配置，不允许页面执行 SQL。保存不会自动开启节点池。

手动上游连接（可选）

上游 Token 加密保存；允许触发的本机 API Key 只保存 HMAC，不回显。这一绑定避免陌生调用方触发独立上游费用。只有节点池和总开关均开启时才会进行自动节点探测。

模型规则（编辑 / 停用 / 删除）

只需在接入其他模型时配置目标长度。未配置或未启用的模型保持透传；全局启动/关闭不修改已有规则。新规则默认有效期 3600 秒、按模型共享；可在编辑中修改。同模型多个会话 / API Key 共用一个固定值与探测任务，原请求仍携带各自认证。多账号或不受信任的多租户环境应选择按 API Key 或更细隔离。

模型目标长度有效期共享范围操作

有效期允许 30–86400 秒，按原采集时间计算而非保存时间；1 小时有效期提前 10 分钟更新。仅修改时长时保留尚可用的固定值；切换到模型共享时合并为最近的一条未过期值，不延长旧期限。保存遵循上方勾选的启用状态。停用保留配置、删除移除配置；两者都会取消该模型的探测并清除其固定值，不影响其他模型。

适用范围：可解析的 HTTP Responses 请求。WebSocket 握手、压缩或超过解析上限的请求保持透传。前置扩展无法感知 sub2api 内部账号切换，跨轮复用仍是兼容实验。上游模型声明和长度匹配不证明实际底层模型身份。
